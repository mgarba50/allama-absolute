# ALLAMA ABSOLUTE User Guide

## Start with a question

Use Question Intelligence to enter one clear question. The system classifies the domain and selects relevant houses/modules. If the wording is ambiguous, compound, accusatory, or asks for impossible certainty, the quality engine can flag it before interpretation.

## Cast

The Raml Shield screen supports:

- manual human tapping across sixteen lines;
- blind tap counts;
- direct Mother selection for paper or external casts;
- cryptographic entropy casting for software-generated trials.

Manual tapping reveals only the odd/even parity after each line is locked. Four completed groups become the four Mothers, then the deterministic engine derives Daughters, Nieces, Witnesses, Judge and Reconciler.

## Inspect

Use House Map to inspect houses 1–12. Use Reverse Judge to trace any of the four Judge lines backward through every derivation to Mother origins.

## Run Omega

Omega Sovereign Analysis combines the already-calculated modules. It displays the question profile, structural validation, traditional testimony, contradiction severity, element distribution, figure migration and the current Judge.

The displayed traditional confidence score is a configured symbolic testimony score. It is not a scientific probability.

## Reports

Scholar Report exports a trace-oriented Markdown dossier. Client Report exports a compact HTML report.

## Commands

The global command bar supports:

- /cast
- /judge
- /reverse
- /house N
- /abjad TEXT
- /hour
- /moon
- /deep

Commands that require case context, such as outcome recording or blind-lock actions, are deliberately not executed from the global shell.

## Language

The shell includes English and Arabic navigation with LTR and RTL switching. Not every analytical paragraph has been translated yet; the coverage audit keeps language marked partial until the entire interface is bilingual.

## Boundaries

Deterministic arithmetic is shown as deterministic arithmetic. Traditional interpretation is labeled traditional. AI synthesis is optional and must not invent missing evidence. Empirical performance requires recorded outcomes. Symbolic analysis is not a substitute for professional medical, legal, financial, or emergency judgment.
