# ALLAMA ABSOLUTE Architecture

## Governing rule

The system separates four evidence classes throughout the architecture:

1. deterministic computation;
2. traditional/esoteric interpretation;
3. AI synthesis;
4. empirical outcome evidence.

A deterministic value is never silently converted into a spiritual or statistical claim.

## Runnable core

The repository contains a browser-runnable TypeScript/React command center with:

- deterministic 16-figure Raml model;
- four-Mother shield derivation through Daughters, Nieces, Witnesses, Judge and Reconciler;
- shield validation and derivation lineage;
- cryptographic entropy casting using Web Crypto;
- Arabic normalization with visible normalized output;
- Abjad Kabir arithmetic, digit reduction and modulus analysis;
- turned-house arithmetic;
- deterministic question routing for initial domains;
- weighted evidence/verdict primitive with contradiction penalty;
- planetary day/hour calculations based on sunrise and sunset;
- Moon illumination/phase context;
- blind-prediction SHA-256 locking primitive;
- JSON and CSV export helpers;
- normalized SQLite schema for cases, casts, predictions, outcomes, rules, sources, celestial data, experiments and calibration;
- automated tests and completion audit.

## Module responsibilities

src/core/raml.ts: shield mathematics.
src/core/figures.ts: figure atlas baseline.
src/core/abjad.ts: Arabic normalization and Abjad arithmetic.
src/core/houses.ts: house and turned-house mathematics.
src/core/question.ts: deterministic question classification baseline.
src/core/celestial.ts: celestial timing calculations.
src/core/verdict.ts: evidence weighting and confidence primitive.
src/core/experiments.ts: blind-lock integrity.
database/schema.sql: local research data model.
tests: known-answer and invariant tests.

## High-stakes discipline

Health, legal, financial and safety-critical questions may be tagged for traditional symbolic research, but the interface must not represent symbolic outputs as professional diagnosis, legal judgment, guaranteed financial outcome, or emergency guidance.

## Provenance discipline

Figure patterns are encoded explicitly and every derived shield figure is reproducible from its parents. Traditional correspondence data must expand with source-level provenance and school labels rather than collapsing conflicting traditions into one undocumented table.
